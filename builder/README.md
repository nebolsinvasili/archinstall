# EasyArch
----------------------------------------
Для запуска скрипта одной командой

```bash
pacman -Sy git ; git clone https://codeberg.org/linuxshef/easyarch.git ; cd easyarch ; ./easyarch
```
--------------------------------------------

Для запуска скрипта последовательно

```bash
pacman -Sy git ; git clone https://codeberg.org/linuxshef/easyarch.git 

cd easyarch

./easyarch
```

--------------------------------------------

На ошибки в процессе выполнения команды по поводу git - не обращаем внимания .

--------------------------------------------

Пароль root устанавливается такой же как пароль пользователя по умолчанию.


The root password is set to the same as the default user password.
