# EasyArch
----------------------------------------
Скрипт состоит из точки входа `archinstall` и модулей из `lib/`, поэтому
запускать нужно каталог `builder` целиком:

```bash
sudo ./archinstall
```
--------------------------------------------

Структура:

| Файл | Назначение |
| --- | --- |
| `archinstall` | точка входа: подключает модули и запускает установку |
| `lib/core.sh` | глобальные переменные, баннер установщика |
| `lib/ui.sh` | диалоги `whiptail` |
| `lib/pacman.sh` | конфигурация pacman, база пакетов, зеркала |
| `lib/disk.sh` | диски, разделы, монтирование, очистка |
| `lib/partition.sh` | ручная разметка диска (cfdisk, ФС, LUKS) |
| `lib/locale.sh` | язык, регион, локали, консоль |
| `lib/user.sh` | пользователи, zsh, стандартные папки |
| `lib/aur.sh` | установка yay (помощника AUR) по умолчанию |
| `lib/hardware.sh` | драйверы видеокарт |
| `lib/bootloader.sh` | GRUB и другие ОС |
| `lib/desktop.sh` | рабочие столы и оконные менеджеры, для KDE Plasma и GNOME есть полные и облегчённые версии |
| `lib/kernel.sh` | выбор ядра |
| `lib/menus.sh` | меню установщика |
| `lib/install.sh` | сценарии автоустановки и ручной установки |

Модули подключаются в указанном порядке, каждый имеет защиту от повторного
подключения (`__<ИМЯ>_SH`) и не запускается отдельно.

Оригинальный скрипт для запуска одной командой

```bash
pacman -Sy git ; git clone https://codeberg.org/linuxshef/easyarch.git ; cd easyarch ; ./easyarch
```
--------------------------------------------

Для запуска скрипта последовательно

```bash
pacman -Sy git ; git clone https://codeberg.org/linuxshef/easyarch.git 

cd easyarch

./easyarch
```

--------------------------------------------

На ошибки в процессе выполнения команды по поводу git - не обращаем внимания .

--------------------------------------------

Пароль root устанавливается такой же как пароль пользователя по умолчанию.


The root password is set to the same as the default user password.
